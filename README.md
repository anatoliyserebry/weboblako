# Моё облако

Небольшое веб-приложение на Flask. Аккаунты и журнал действий хранятся в SQLite,
файлы передаются через локальный FTPS-сервер. Интерфейс — HTML, CSS и немного JavaScript для поиска.

## Запуск в Windows

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Адрес: http://127.0.0.1:8080. При первом запуске нужно создать администратора.
Следующие аккаунты можно зарегистрировать на странице входа или создать из раздела «Пользователи».

## Возможности

- У каждого пользователя отдельное хранилище с личными папками.
- Можно создавать папки, загружать, скачивать и переименовывать файлы.
- Удаление переносит файл или папку вместе с содержимым в корзину.
- Из корзины можно восстановить объект либо удалить его навсегда.
- Общая ссылка даёт вошедшему пользователю право просмотра и скачивания одной папки и её вложенных папок.
- Владелец может отключить ссылку. Удаление общей папки также отключает её ссылки; восстановление не включает их заново.
- Посещённые общие папки отображаются в разделе «Со мной поделились».
- История показывает автора, время и действие: добавление, переименование, удаление, восстановление и изменение доступа.
- Сортировка работает по названию, расширению файла и размеру; папки остаются в начале.

Один файл — до 20 МБ, квота пользователя — 100 МБ, включая корзину.
Если исходная папка была удалена, сначала нужно восстановить её, затем вложенный файл.
При совпадении имён восстановление не перезаписывает существующий файл.
Время в журнале и корзине указано в UTC. История хранит события, а не предыдущие версии содержимого файлов.
Журнал начинается с действий, совершённых после добавления этой функции.

Приложение запускается на локальном компьютере. Ссылки используют адрес этого же приложения.

## Структура

- `app.py` — маршруты, проверка доступа и операции с файлами через FTPS.
- `database.py` — аккаунты и пароли.
- `file_records.py` — корзина, общие ссылки и история действий.
- `storage.py` — FTPS-сервер, изоляция хранилищ и проверка имён.
- `templates/` и `static/` — страницы, стили и поиск по названию.
- `data/accounts.sqlite3` — база данных; новые таблицы создаются автоматически.
- `data/files/<id пользователя>/` — личные файлы; `.trash/` внутри хранит содержимое корзины.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Проверки используют временные базы и файлы. Они проверяют изоляцию пользователей,
права общих ссылок, корзину, конфликты при восстановлении, журнал, сортировку,
сохранение данных после перезапуска и переход с прежней базы.
